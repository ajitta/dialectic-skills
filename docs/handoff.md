## How a run is set up (Claude Code)

- `claude -p` with `--plugin-dir <copy>` and `--add-dir <copy>` (a copy of `plugins/dia` outside the repository, never the repository folder), `--model claude-fable-5-2 --effort high`, `--output-format stream-json --verbose`, started in an empty folder outside the repository (at the repository root `CLAUDE.md` loads `AGENTS.md`, which confounds the run).
- Every run gets a fresh `CLAUDE_CONFIG_DIR` holding only a copy of `.credentials.json`, deleted afterwards. Set `ENABLE_CLAUDEAI_MCP_SERVERS=false`. The account's plugins and skills sync into a run's config during a turn, and removing `<config>/plugins/synced` and `<config>/skills/synced` before a resumed turn does not keep the skills out. What does: a `settings.json` in the fresh folder with `"syncClaudeAiSkills": false` and `"syncClaudeAiPlugins": false` (without them 26 account skills were listed at the third of three short turns, with them none in four). `run_a.py` writes it for every run and for the simulated user. Discard a run whose `system/init` event, in any turn, lists an `@synced` plugin or an `anthropic-skills:` skill.
- Never run on the home configuration: its hook `~/.claude/hooks/dia-lab-before.py` changes how dia skills start. Do not renew the login token with a `claude -p` call from the home configuration.
- A run is void unless its events show the skill loaded, the opening words of the branch's text, plugin `dia` at the version under test and no synced plugin. `run_b.py` checks these and writes them into the record. Since Stage D it also marks a run void when any `init` event of any turn lists an `anthropic-skills:` skill.
- The run is told the real date ("Today's date is" in `-sent.txt`). Read a task's dates against the day of the run before running it.
- A resumed `claude -p` reports cost cumulatively. The simulated user is a separate `claude -p` with no plugin and no tools at effort low; it is given the persona and writes every first message where the task has a persona.
- After editing a skill on the unreleased branch: delete `plugin-release.json`, run `python tools/package.py`, and confirm the new text is in `plugins/dia/` before copying it.
