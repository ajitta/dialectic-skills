# Review of the text

- D1. Lindqvist (2021) found 40% fewer post-release defects overall, but the reduction was close to zero for routine tasks, so S1's "on every task" is wrong.
- D2. 15% of a ten-person team is 0.15 developers, not one and a half, so S2's figure is wrong.
- D3. The extra effort fell from 30% in the first two months to about 10% after six months (Lindqvist 2021), so S3 is false.
- D4. Satisfaction was measured only in the final month (Lindqvist 2021), so S6's "throughout the study" is not supported.
