`business_days_between`를 고쳤습니다. 원인은 휴일을 빼는 마지막 줄이었습니다. 주말을 세는 부분은 문제가 없었습니다.

**원인**

```python
count -= sum(1 for h in holidays if start < h <= end)
```

이 줄 때문에 두 경우에 값이 틀렸습니다.

1. **주말에 걸린 휴일도 뺐습니다.** 토요일이나 일요일은 애초에 세지 않았는데, 같은 날이 휴일 목록에 있으면 한 번 더 빠졌습니다.
   예: 2026-10-30(금) → 2026-11-06(금), 휴일 = 10-31(토). 정답은 5인데 4가 나왔습니다.
2. **같은 날짜가 목록에 두 번 있으면 두 번 뺐습니다.** 여러 휴일 목록을 합칠 때 흔히 생기는 경우입니다.
   예: 같은 구간, 휴일 = [11-02(월), 11-02(월)]. 정답은 4인데 3이 나왔습니다.

"가끔" 틀렸던 건, 휴일이 주말에 걸리거나 날짜가 중복될 때만 증상이 나타났기 때문입니다.

**수정 내용** (`/home/claude/exp/p3/runs/R1_B/bizdays.py`)

- 휴일을 `set`으로 모아 중복을 없앴습니다.
- 구간 안에 있고 평일(`weekday() < 5`)인 휴일만 뺍니다.
- `start > end`이면 원래 코드는 평일 수를 음수로 돌려주면서 휴일은 하나도 빼지 않았습니다. 이제는 이 경우에도 휴일을 반영해서, 정방향 결과에 부호만 바뀐 값이 나옵니다. 나머지 동작(`start` 다음 날부터 `end`까지 포함하는 규칙, 인자 형태)은 그대로입니다.
