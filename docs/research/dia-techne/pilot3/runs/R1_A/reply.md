목표: `business_days_between`이 어떤 입력에서든 docstring에 적힌 대로 "`start` 다음 날부터 `end`까지(포함), 주말과 휴일을 뺀 날 수"를 내게 하고, 그게 맞다는 걸 모델의 추론이 아닌 바깥 기준으로 확인하는 것.

  - 휴일 없이: 40×40 = 1,600개 날짜 쌍(정방향·역방향)에서 불일치 0건. 주 단위 계산 자체는 맞았습니다.
  - 휴일 포함 정방향 20,000건 중 2,664건 불일치. 문제는 휴일 처리에만 있었습니다.

  1. **주말에 걸린 휴일도 빼던 문제**: 토/일은 애초에 세지 않았는데 휴일 목록에 있으면 한 번 더 뺐습니다. 예: 2026-11-02(월)~11-09(월), 휴일 11-07(토) → 기존 4, 맞는 값 5.
  2. **같은 휴일이 두 번 들어오면 두 번 빼던 문제**: 예: 휴일 [11-04, 11-04] → 기존 3, 맞는 값 4.
  3. **역방향(`end < start`)일 때 휴일을 무시하던 문제**: `start < h <= end`가 절대 참이 될 수 없습니다. 예: 11-06(금)→11-04(수), 휴일 11-05(목) → 기존 -2, 맞는 값 -1.
