# upstream (reference archive)

Reference material that the `dia` skills of [ajitta/dialectic-skills](https://github.com/ajitta/dialectic-skills) were rebuilt from (spec §11 there). It was kept under `upstream/` on `main` until 2026-10-21 and moved to this orphan branch (spec D36) so that skill directories that crawl the default branch do not list these old skills as installable. The content is byte-identical to `upstream/` at `main` commit `eb7ab54`; the SHA-256 values in `upstream/README.md` still hold.

This branch is not a plugin, not a marketplace and not maintained. Do not install from it. Paths such as `upstream/installed/reductio/SKILL.md` cited in the main branch's research and review documents refer to this tree.
